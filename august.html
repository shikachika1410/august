☁️ Cloud Sync (biar bisa dibuka di HP lain)

Data otomatis kesimpen di browser ini (localStorage). Biar bisa kebuka di HP/device lain dan angkanya sama, pakai JSONBin.io (gratis, cukup login pakai akun Google/GitHub). Cukup isi Access Key di bawah, terus pencet Buat Bin Otomatis — Bin ID bakal ke-generate sendiri.

Buka jsonbin.io → Login pakai Google/GitHub → masuk ke halaman API Keys → copy X-Master-Key / Access Key kamu, paste di bawah.

Belum pernah sync.

📱 Di HP/device lain: cukup isi Access Key yang sama + Bin ID yang tadi udah ke-generate (tinggal copy dari sini), terus pencet Simpan Setelan → Pull. Nggak perlu klik "Buat Bin Otomatis" lagi.

🔗 Bagikan Link View Only

Orang yang buka link ini cuma bisa lihat Recap (ringkasan + riwayat lengkap) dan nggak bisa nambah/edit/hapus apapun. Wajib aktifin Cloud Sync dulu di atas & pencet Push, biar datanya kebawa ke link ini.

Disaranin: jangan pakai Access/Master Key kamu buat link ini (soalnya kalau ke-inspect, orang bisa pakai key itu buat edit data lewat API). Mending bikin Access Key baru khusus read-only di jsonbin.io (menu API Keys → Create Access Key → centang izin "Get Bin" doang), terus paste di bawah.
